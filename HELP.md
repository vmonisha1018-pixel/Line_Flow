\# LINEFLOW - HELP



LineFlow is a simple command-line text editor.



Commands:



i - Insert a new line

d - Delete an existing line

p - Display the document

q - Quit the program



Insert:

Enter i and give the line number and text to insert.



Delete:

Enter d and give the line number to delete.



Display:

Enter p to display all lines in the document.



Quit:

Enter q to exit LineFlow.



Example:



Enter command: i

Enter line number: 1

Enter text: Hello World



Enter command: p
